# KeyFlip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver an offline .NET 8 WinForms tray utility that converts selected US/Russian layout-mistyped text safely with a global hotkey.

**Architecture:** A hidden WinForms host owns the tray icon and `WM_HOTKEY`. Pure conversion is isolated in `LayoutConverter`; Win32 services perform serialized Copy → Convert → Paste with clipboard sequence validation and terminal exclusions.

**Tech Stack:** C# 12, .NET 8, WinForms, Win32 P/Invoke, xUnit, no third-party runtime dependencies.

## Global Constraints

- Windows 10/11 x64; C#/.NET 8/WinForms only.
- Offline only: no AI, API, network, telemetry, analytics, or cloud services.
- Never log, persist, or publish selected text or clipboard contents.
- Terminals are excluded; browsers and VS Code are in scope.
- Map standard physical US QWERTY ↔ Windows Russian ЙЦУКЕН keys, including shifted symbols.
- Run unit tests after converter edits and build after integration edits.
- Work directly on branch `main`; keep dependencies minimal.

**Interfaces:** `Task<ClipboardCopyResult> CopySelectedTextAsync(...)` returns text only after sequence change; `Task ReplaceSelectionAsync(string, ...)` restores the previous `IDataObject` after paste where possible.
