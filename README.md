[![MIT License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

KeyFlip — небольшая бесплатная Windows-утилита для исправления выделенного текста, набранного в неправильной русской или английской раскладке.

`ghbdtn` → `привет` · `руддщ` → `hello`

Выделите текст и нажмите `Ctrl + Shift + K`. Всё работает локально и офлайн: без AI, аккаунта, телеметрии и отправки текста в интернет.

![KeyFlip исправляет раскладку текста](assets/readme/keyflip-demo.png)

## Быстрый старт

1. Скачайте `KeyFlip_windows_x64.exe` из официального GitHub Release.
2. Поместите файл в постоянную папку и запустите.
3. Выделите текст в поддерживаемом приложении.
4. Нажмите `Ctrl + Shift + K`.
5. Настройте горячую клавишу и автозапуск через значок KeyFlip в системном трее.

После переноса portable EXE запустите его вручную один раз, чтобы KeyFlip обновил путь автозапуска.

![Настройки KeyFlip](assets/readme/keyflip-settings.png)

Текущая версия приложения указана в заголовке окна настроек рядом с кнопкой закрытия.

## Возможности

- Контекстное преобразование русского и английского текста с определением направления для локальных фраз.
- Полная физическая карта US QWERTY ↔ ЙЦУКЕН, включая Shift и символы.
- Code-aware режим, сохраняющий корректный синтаксис и исправляющий уверенно распознанный wrong-layout синтаксис.
- Сохранение форматирования и структуры абзацев в Microsoft Word.
- Преобразование имён файлов в Проводнике с сохранением последнего расширения и точных пробелов.
- Настраиваемая глобальная горячая клавиша, системный трей и автозапуск Windows.
- Защита полей паролей и исключение терминалов.
- Снимок и безопасное восстановление буфера обмена.
- Полностью локальная и офлайн-работа без сетевых функций.

## Как это работает

Для одного буквенного токена KeyFlip выполняет прямое физическое преобразование раскладки. В длинных фразах приложение определяет направление для локального смыслового сегмента, а затем единообразно обрабатывает неоднозначные физические группы клавиш. Известные технические сокращения вроде `SQL`, `API` и `HTTP`, URL, email и подтверждённые английские фрагменты защищены от случайной замены. Пробелы, табуляции и переводы строк сохраняются точно; пунктуация рядом с преобразованным словом меняется в том же направлении.

Последовательность обычной операции: проверка защищённого контекста → сохранение буфера обмена → Copy → преобразование → Paste → восстановление буфера. Подтверждённый VS Code Integrated Terminal останавливает операцию до `Ctrl+C` и изменения буфера; editor и неизвестный контекст `Code.exe` продолжают работать.

В code context сначала строится безопасный вариант с сохранением существующей ASCII-пунктуации. Wrong-layout кавычки и другие синтаксические позиции меняются только при сильных признаках кода. В Microsoft Word применяются точечные замены Range, а в подтверждённом режиме переименования Проводника — отдельная filename-policy с сохранением расширения.

## Безопасность и приватность

KeyFlip не отправляет текст, не использует AI, не собирает телеметрию, не требует аккаунт или интернет и не сохраняет выделенный текст. Диагностический журнал содержит только безопасные стадии операции, версию и классификацию контекста — без текста, команд терминала и содержимого буфера обмена.

EXE пока не подписан цифровой подписью, поэтому Windows SmartScreen или антивирус могут показать предупреждение. Не отключайте защиту: скачивайте файл только из [официального релиза](https://github.com/pologovlev-collab/KeyFlip/releases), сверяйте SHA-256 или собирайте приложение самостоятельно.

SHA-256 каждой сборки публикуется в описании соответствующего GitHub Release. После скачивания файл можно проверить командой:

```powershell
Get-FileHash .\KeyFlip_windows_x64.exe -Algorithm SHA256
```

## Известные ограничения

- Приложения с повышенными правами могут отклонять синтетический ввод из-за границ безопасности Windows.
- Поля паролей и подтверждённые терминалы намеренно игнорируются.
- При редком неподдерживаемом формате буфера обмена операция безопасно прерывается.
- Смешанное форматирование внутри одного слова Microsoft Word может стать единообразным.
- Необычные Word add-ins и custom hosts могут не предоставить безопасный automation context.
- Необычная пунктуация, полностью набранная в неправильной раскладке, может остаться без изменения при неоднозначном контексте.
